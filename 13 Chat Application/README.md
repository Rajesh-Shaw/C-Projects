# Chat Application using C (TCP Sockets)

A simple LAN-based chat application using C socket programming.
Supports multiple clients chatting through a common server.

## Features
- Real-time messaging
- Multi-client broadcast
- Usernames
- Runs on Windows/Linux/macOS

## How to Run

### 1. Compile Server
gcc server.c -o server

### 2. Compile Client
gcc client.c -o client

### 3. Run Server
./server

### 4. Run Multiple Clients
./client

## Requirements
- GCC compiler
- Basic understanding of sockets
